# Blackjack_Assignment2

This repository contains the code and outputs for Assignment 2 for CPSC 4420. The project uses tabular Q-learning to train a Blackjack agent in Gymnasium, compares different learning rates, discount factors, and exploration rates, and evaluates the trained policies.

## Setup and Run Instructions

1. Download the `.ipynb` notebook and open it in Jupyter Notebook, or upload it to Google Colab.
2. For set up, please pip install required packages.
3. Run all notebook cells in order from top to bottom.

## Outputs

The repository includes training plots, an evaluation comparison plot, and MP4 recordings of the trained agent. When running the notebook, PNG files are saved in the 'Images'folder, and recordings are saved in the 'Videos' folder.

Blackjack episodes are short, so the video recordings are brief.
