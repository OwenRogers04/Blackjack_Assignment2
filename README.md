# Blackjack_Assignment2

This repository contains the code and the outputs for assignment two for CPSC-4420.
The code is a jupiter notebook, so for ease of use, copy the code and paste into either
a google colab notebook, or another jupiter notebook. Some instalations might be required. 
Please pip install them straight into the notebook, or colab to do this. After that, the code
should run by simply running the cells. Since it is blackjack, the videos and episodes are 
very quick.
